## Решения, которые ждут владельца

1. **Компьютер с RTX 5070 Ti** (16 ГБ видеопамяти, 96 ГБ RAM): как дать доступ —
   Claude Code на нём (рекомендуется), SSH с ноутбука или вручную по инструкции.
   От этого зависят видеоклипы (#39) и большая библиотека.
2. **Hugging Face PRO ($9/мес)** — крайний случай, только по решению владельца.
3. **Ранние пробуждения** («СИМУЛЯНТ», «мозг решил, что хватит») в фильме не
   возникают: температуры, которой управлял игрок, больше нет. Нужны ли они —
   монтаж может разыгрывать их по seed.
4. **Вертикальный экран**: широкий кадр обрезается по бокам; возможно, нужен
   тег «важная точка кадра» в манифесте.
5. Оценка плеера на слух и глаз: страшно ли, реалистично ли — после появления
   библиотеки.
6. Идея #15 («при 38,5 гигантские шары и квадраты») — в бэклоге.

## Как продолжить новой сессии

1. Прочитать [AGENTS.md](../AGENTS.md), [vision.md](vision.md),
   [decisions.md](decisions.md) (с D-022), [generation-plan.md](generation-plan.md)
   и этот файл.
2. `git fetch`, посмотреть эпик #42 и ветки `44-local-generation`,
   `35-library-v0`.
3. Порядок: доделать #44 → добрать кадры #35 (квота или локальная генерация) →
   #36; параллельно #40.
4. Работать в стиле первого среза: до трёх субагентов параллельно в отдельных
   worktree, каждый открывает PR и не сливает; основная сессия ревьюит и
   сливает после зелёного CI.

## Грабли этой сессии

- **Лимиты.** Субагенты часто обрываются по лимиту API. В задании требовать
  промежуточные WIP-коммиты и проверку, что агент в своём worktree. Возобновлять
  через SendMessage с тем же агентом; если worktree не создался — запускать
  заново.
- **Незавершённая ветка агента** может существовать только локально: отправлять
  её на GitHub до любой перезагрузки.
- **Фоновые процессы на Windows** (vite, MCP-серверы браузера) не умирают сами
  и держат папки worktree. Требовать от агентов останавливать свои серверы;
  застрявшие — находить по командной строке и останавливать, не трогая чужие
  проекты.
- **Удаление worktree**: `git worktree remove` падает на длинных путях
  `node_modules` — помогает `rm -rf` и `git worktree prune`.
- **Параллельные агенты и общие файлы** (`main.ts`, `docs/decisions.md`,
  `ENGINE_VERSION`, снапшоты): заранее раздавать номера решений и версий,
  сообщать агентам о каждом слиянии, общий контракт задавать до запуска.
- **Эпики**: задачи привязывать как подзадачи, список в теле — без чекбоксов.
- **Служебные скрипты** не запускать из папки репозитория: их временные файлы
  попадают в `git add -A`.
- **Перегрев**: три агента со сборками и тестами держат ноутбук около 70 °C
  при ~50 % CPU; генерацию запускать только через `thermal.py`.
