## Локальная генерация на ноутбуке: что известно

Пачка из 10 кадров 2026-10-09 (лог —
`tools/generation/logs/batch10-2026-10-09.csv`, вне git; выдержка — в PR #55):

| Этап | Время | Температура до → пик → после |
|---|---|---|
| Загрузка кодировщика (видеокарта) | 12 с | 70 → 70 → 63 °C |
| Промпт (видеокарта) | 3,3 с первый, 0,4 с следующие | не выше 67 °C |
| Кадр 1280×720, 8 шагов (видеокарта) | 56–60 с | 55–66 → **83–86** → 70–75 °C |

- Пачка — 21 минута, около 2 минут на кадр с отдыхом, без пауз и аварийных
  остановок. Запуск: `generate.py --profile laptop --gguf
  unsloth/Z-Image-Turbo-GGUF/z-image-turbo-Q6_K.gguf --limit 10`.
- **Кодировать промпты только на видеокарте** (умолчание). На CPU —
  88–89 °C на каждом промпте даже в 4 потока.
- **Пик кадра 83–86 °C** — в 4–7 градусах от аварийной остановки (90 °C).
  Раньше в логе было 81 °C только потому, что датчик опрашивался раз в 5 секунд.
  Нужно ли снижать — вопрос владельцу в PR #55.
- **Во время пачки ничего тяжёлого не запускать**: сборка и тесты, запущенные
  параллельно, подняли пик кадра до 89,1 °C; при двух работающих агентах защита
  аварийно остановила прогон на 92 °C, когда генератор стоял на паузе.
- Ноутбук должен быть **на зарядке**: на батарее защита отказывает в запуске.
- Закодированные промпты лежат в `tools/generation/cache/embeds/` (вне git);
  в ветках, отведённых до #55, эта папка видна как неотслеживаемая — не
  коммитить.
- Окружение: `tools/generation/.venv` (вне git, PyTorch XPU), модели в кэше
  `~/.cache/huggingface/hub`. При запуске не ставить `HF_HUB_OFFLINE=1`.
- Карты глубины для новых кадров: `cd tools/depth && pnpm install && node
  depth.mjs` (3 с на кадр, пик 72 °C). Без них тест библиотеки красный.

Бесплатная квота Hugging Face (Space `mcp-tools/Z-Image-Turbo` через MCP)
**снова работает** с 2026-10-30: 10 запросов подряд без отказа. Решение
владельца: пока квота есть, новые кадры делать через неё, а не на ноутбуке;
ноутбук — потом, в щадящем режиме. Промпты кадров с Hugging Face — в манифесте
и в `prompts.json` (сцена + `seed`).

## Генерация на компьютере (ComfyUI по сети)

Основной источник кадров и клипов с #147 (D-042). Компьютер владельца с RTX
5070 Ti в Tailscale: `desktop-jtmbpel`, ComfyUI на `http://100.105.208.82:8188`.
Модели: Z-Image-Turbo (кадры), Wan 2.2 TI2V-5B (клипы, 1280×704, 121 кадр,
24 к/с, ~5 с).

Цикл одной партии:

1. **Каталог.** Сцены кадров — `tools/generation/prompts.json` (сцена +
   `seed`), клипы — `tools/comfy/clips.json` (`from` — входной кадр
   библиотеки, свои теги клипа поверх кадра). Список для владельца — раздел 6
   [desktop.md](desktop.md). Это PR по задаче партии.
2. **Заказ.** `tools/comfy/orders/<имя>.json` (вне git, кроме
   `example.json`): `name`, `url`, списки `stills`/`clips`, `variants` —
   сколько seed на сюжет (кадры: seed +1, клипы: seed +10).
3. **Генерация** — не основная сессия, а лёгкая модель: владелец запускает
   Claude Haiku командой `/comfy-order <имя>` (инструкция —
   `tools/comfy/AGENT.md`). Клип — 5–15 минут, 80 клипов — около 6,5 часа.
   Результаты: `tools/comfy/out/<заказ>/<id>_<seed>.{png,mp4,json}` (вне git).
4. **Ревью.** Полосы кадров через `ffmpeg` (`fps=2,scale=240:-1,tile=10x1`,
   четыре seed одного сюжета в столбик через `vstack`), смотреть глазами.
   У клипов падения отмечать, на какой секунде рывок.
5. **Отбор владельцем.** Страница `tools/comfy/out/select.html` (вторая
   партия) или `select3.html` (третья). Генераторы — в
   `tools/comfy/out/select/` (вне git): `node select-page3.mjs <корень
   репозитория>`; для новой партии поменять `orders`, ключ `localStorage`,
   заголовок и оценки `picks`. Страница открывается из проводника. Владелец
   присылает JSON `{"clips": ["id@seed", …]}`.
6. **Перевод в библиотеку** в отдельном worktree:
   `node tools/comfy/comfy.mjs import --out <папка заказа> id_seed[:обрезка]…`.
   Несколько seed одного id — варианты: первый получает id, дальше `-2`,
   `-3`…, поэтому лучший ставить первым. `:2.4` срезает начало клипа: плеер
   показывает середину клипа (#141), и у резких падений начало обрезается
   примерно за 0,5 с до рывка. Вариант кадра сам получает свою сцену в
   `prompts.json`.
7. **Проверки.** Новым кадрам — карты глубины: `cd tools/depth && node
   depth.mjs` (CPU, ~24 мин на 60 кадров, пик 68 °C). Затем `pnpm
   typecheck/lint/test/build`, `node --test` в `tools/comfy`, проба на 300
   снах (временный vitest-файл пишет итог в файл: консоль vitest его не
   показывает; удалить перед коммитом). PR с адресами проверки, слияние
   после зелёного CI.

Что известно о результатах:

- **Резкое падение** Wan делает плохо: почти всегда держит неподвижный кадр
  2–3,5 с и только потом срывается, даже с «For half a second nothing
  moves». Лучше всех вышел лифт с крыши в шахту (рывок на 1–2 с). Отсюда
  обрезка при переводе.
- Часть «тихих» клипов почти неподвижна (монитор, ртуть, окна, лампы);
  владелец их всё равно берёт для спокойных шотов.
- Бывает уход цвета (фиолетовый, оранжевый) и двоение объекта (куб).

## Как продолжить новой сессии

1. Прочитать [AGENTS.md](../AGENTS.md), [vision.md](vision.md),
   [decisions.md](decisions.md) (с D-022) и этот файл.
2. `git fetch`, `git status`; открытые задачи — `gh issue list`.
3. Спросить владельца, что он увидел на плейтесте, и идти по разделу
   «Что дальше».
4. Работать в отдельном worktree (`.claude/worktrees/NN`): в основной копии

5. Серверы (`pnpm dev`, страница отбора) без нужды в фоне не держать: при
   нехватке памяти Claude Code их останавливает. Поднимать по просьбе
   владельца.

## Грабли этой сессии

- **Лимиты.** Субагенты часто обрываются по лимиту API. В задании требовать
  промежуточные WIP-коммиты и проверку, что агент в своём worktree. Возобновлять
  через SendMessage с тем же агентом; если worktree не создался — запускать
  заново.
- **Незавершённая ветка агента** может существовать только локально: отправлять
  её на GitHub до любой перезагрузки.
- **Фоновые процессы на Windows** (vite, MCP-серверы браузера) не умирают сами
  и держат папки worktree. Требовать от агентов останавливать свои серверы;
  застрявшие — находить по командной строке и останавливать, не трогая чужие
  проекты.
- **Удаление worktree**: `git worktree remove` падает на длинных путях
  `node_modules` — помогает `rm -rf` и `git worktree prune`.
- **Бракованный кадр**: модель иногда выдаёт картинку не по промпту (вместо
  спальни — город). Каждый новый кадр смотреть глазами до коммита; помогает
  короче описать сцену и задать `seed` в `prompts.json`.
- **Параллельные агенты и общие файлы** (`main.ts`, `docs/decisions.md`,
  `ENGINE_VERSION`, снапшоты): заранее раздавать номера решений и версий,
  сообщать агентам о каждом слиянии, общий контракт задавать до запуска.
- **Эпики**: задачи привязывать как подзадачи, список в теле — без чекбоксов.
- **Служебные скрипты** не запускать из папки репозитория: их временные файлы
  попадают в `git add -A`.
- **Перегрев**: три агента со сборками и тестами держат ноутбук около 70 °C
  при ~50 % CPU; генерацию запускать только через `thermal.py` и только когда
  агенты и сборки не работают.
- **Слияние PR** основной сессией может заблокировать защита Claude Code
  («слияние без ревью»): тогда спросить владельца, а не обходить.
- **Общий браузер Playwright MCP** один на всех агентов: параллельные агенты
  уводят друг у друга вкладку. Давать каждому свой headless-браузер.
- **Авторство коммитов**: почта `pmiskevich@gmail.com` на GitHub привязана к
  аккаунту `pmiskevich-cmd`. Коммитить только с
  `48240641+pavelmiskevich@users.noreply.github.com` (стоит в настройках git
  репозитория; на новом компьютере — `git config --global`). Почту в GitHub
  владелец не меняет (решение 2026-11-03).
- **Python и кириллица**: вывод в консоль Windows падает с
  `UnicodeEncodeError` (cp1252) — ставить `PYTHONIOENCODING=utf-8`, тексты PR
  писать в файл и передавать через `gh pr create/edit --body-file`.
- **Цепочка `&&` с проверками**: если скрипт правки упал на `assert`, а коммит и
  push стояли в той же цепочке через `;` или после неотловленной ошибки —
  в ветку уйдёт половина правок. Сначала проверить результат, потом коммитить.
- **Тесты, зависящие от содержимого библиотеки** (`tools/comfy/comfy.test.mjs`)
  ломаются после очередного перевода: строить в них свой список «чего не
  хватает», а не брать настоящую библиотеку.
- **«Тот же кадр» — через сюжет.** Варианты одного сюжета раньше были для
  монтажа разными кадрами — исправлено в #158 (`subjectsOf`). Новое правило
  монтажа про повтор кадра проверять по сюжету, а не по `asset.id`.
- **Сканер injection-guard** срабатывает на `tools/comfy/AGENT.md` («запусти
  ту же команду») — это наша инструкция для Haiku, а не инъекция.
- **Длинные скрипты через heredoc** в Bash иногда обрываются: писать скрипт
  в файл и запускать файл.
