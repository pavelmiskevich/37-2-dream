# 3. Скримеры, температура, звук

Спецификация v1.1, разделы 16–17, 20–22. Приоритет — у
[vision.md](../vision.md) и [decisions.md](../decisions.md).

## 16. Скример-система

Скримеры делятся на:

1. Visual.
2. Audio.
3. Video.
4. False scare.
5. Delayed scare.
6. Environmental scare.

### Важное правило

Скример нельзя выбирать полностью случайно. У него должны быть:

```text
Trigger
Anticipation
Misdirection
Scare
Recovery
Cooldown
```

Пример:

```text
пустой коридор
→ пиканье
→ открывающийся лифт
→ ожидание монстра
→ голубь
→ расслабление
→ через 3 секунды настоящий скример
```

> **Дополнено решением [D-009](../decisions.md#d-009-скримеры-и-светочувствительность):**
> предупреждение перед игрой и настройка «без вспышек и скримеров».

## 17. Видеоскримеры

> **Отложено решением [D-006](../decisions.md#d-006-художественное-направление-под-агентов):**
> в первых срезах скримеры делаются средствами движка.

Допускаются короткие pre-rendered video clips. Рекомендуемая продолжительность:

- 100–300 мс — flash scare;
- 300–800 мс — быстрый visual scare;
- 1–2 секунды — cinematic scare.

Темы:

- лицо;
- силуэт;
- человек в окне;
- человек на качелях;
- гигантский голубь;
- медицинский монитор;
- женщина с пылесосом;
- собственная кровать;
- собственное лицо.

Видео не должно постоянно повторяться. Используется cooldown и история уже
показанных scare events.

## 20. Температура как глобальный параметр

37,2 °C — не просто текст. Она является состоянием сна:
`temperatureState = 37.2`.

Температура может колебаться: 37.1 → 37.2 → 37.3 → 37.2.

При повышении:

- растёт chromatic aberration;
- увеличивается distortion;
- усиливается звук;
- появляются ошибки физики;
- увеличивается вероятность скримера;
- объекты начинают масштабироваться;
- переходы становятся быстрее.

При снижении:

- мир становится спокойнее;
- звуки приглушаются;
- камера стабилизируется.

> **Уточнено в v1.2:** температурой управляет игрок, это главная механика — см.
> [vision.md](../vision.md#игрок).

## 21. Аудио-архитектура

Аудио разделить на слои:

```text
Ambient → Location → Physics → Recurring → Tension → Scare → Transition
```

Одновременно активны только совместимые слои.

### Основные recurring sounds

- качели;
- ИВЛ;
- монитор;
- пылесос;
- дыхание;
- часы;
- шаги;
- далёкий поезд;
- советский двор;
- электрический гул;
- ветер.

> **Уточнено решениями [D-006](../decisions.md#d-006-художественное-направление-под-агентов)
> и [D-010](../decisions.md#d-010-звук-стартует-по-жесту-игрока):** звук по
> возможности синтезируется; Web Audio разблокируется экраном «Нажмите, чтобы
> уснуть».

## 22. Spatial Audio

> **Отложено:** см. «Сейчас НЕ делаем» в [vision.md](../vision.md#сейчас-не-делаем).

Для desktop:

- Web Audio API;
- positional audio;
- stereo panning;
- distance attenuation;
- low-pass filters;
- reverb zones.

Например: игрок слышит ИВЛ слева. Идёт влево. Звук становится громче.
Поворачивается. Аппарат оказывается за стеной.
