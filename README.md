# 37.2 Dream

*A procedurally generated man-flu fever dream.*

Мужчина с температурой 37,2 °C уверен, что умирает. Игра — его предсмертный бред
от первого лица: советский двор, скрипучие качели, падение сквозь листки
завещания, гигантская банка варенья и женщина с пылесосом, которая ничего не
объясняет. Каждый сон собирается процедурно из seed и воспроизводится по нему.

**37,2 °C. Ничего страшного. Просто приснилось.**

Браузерная игра на TypeScript и Three.js. Статус: подготовка первого
вертикального среза.
