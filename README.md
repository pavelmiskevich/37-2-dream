# 37.2 Dream

*A procedurally generated fever dream.*

Процедурный сон-фильм мужчины с температурой 37,2 °C: реалистичный, абсурдный и
гнетущий. Управления нет — зритель засыпает, и сон собирается заново из seed:
советский двор, пустые качели, больничные коридоры, гигантская банка варенья и
женщина с пылесосом, которая ничего не объясняет. Два сна не похожи друг на
друга, но любой можно пересмотреть по ссылке.

**37,2 °C. Ничего страшного. Просто приснилось.**

Браузерный проект на TypeScript и Three.js; картинка — реалистичные ИИ-кадры из
библиотеки проекта. Статус: поворот от игры к сну-фильму (D-022), прототип.
